# APKShield AI

## Overview

APKShield AI is an AI-powered Android APK Security Analysis Platform.

The project consists of two independent layers.

Backend
↓

Frontend

The backend is considered frozen.

The frontend must consume the backend APIs and never modify backend architecture.
