# F2.1 — Product Homepage

Version: 1.0

Status: Approved

---

# Objective

Build the public homepage of APKShield AI.

The homepage should introduce the product, explain its value, and guide users toward starting an APK analysis.

This page should feel like a premium cybersecurity SaaS product.

---

# User Story

As a first-time visitor,

I want to quickly understand what APKShield AI does,

so that I feel confident uploading an APK for analysis.

---

# Design Philosophy

Inspired by:

- GitHub
- Vercel
- Cloudflare
- Linear

Avoid:

- Cartoon illustrations
- Neon cyberpunk
- Glassmorphism
- Marketing buzzwords

The design should communicate engineering quality.
